# 精细公寓 VR 场景操作说明

现在请打开 `Assets/Scenes/Apartment_Detailed_VR.unity`。精细副本提供右手 B 菜单、可跳过的中文教学、三种移动方式、可保存的舒适度调节（移动暗角 / 速度 / 转向 / 快照转向）、安全重置、右食指扳机开关门，以及参观完成提示和退出游戏。原有 `ApartmentPhase2_VR` 仍保留，不需要再安装第二个玩家或相机。

## 场景为什么不一样

同学的 `apartmentguidence-by` 分支里有 `Assets/Scenes/Apartment.unity`；它与原来的灰盒 `ApartmentPhase2_VR` 不是同一个场景。本次把精细场景及所需家具、材质资源导入当前个人分支 `fzj/teleport`，没有切换分支、提交或推送 GitHub。

`Apartment.unity` 保持导入时的内容不变。所有玩家接线、空心柜体、新柜门、家具通路调整和教学组件只保存在 `Apartment_Detailed_VR` 副本中。共用移动脚本保留旧导航模式；原灰盒 VR 场景继续使用旧模式，未配置教程的场景仍显示原来的柜门操作提示。

精细场景中的建筑使用 ProBuilder，因此新增 `com.unity.probuilder` 6.1.2 依赖。之前已修好的 Meta 三个包版本仍为 205.0.0，不改回同学电脑上的 E 盘路径。

保留同学的双手和手柄外观，但停用其旧移动控制器、身体碰撞体及对应的视野遮罩，只由原 `ApartmentVRLocomotion` 控制玩家。否则两个移动系统会竞争位置，残留的遮罩也可能把画面缩成一个小圆圈。

## Quest 3 的操作

- 左摇杆：走路。
- 右摇杆：连续转向，原速度参数不变。
- 右手 A 键：按住瞄准，绿色落点时松开传送，最远 5 米。不再要求导航地图连通或沿途能走过去；落点仍须是有身体空间的地面，弧线不能穿过实体。
- 右手食指扳机：指向门，出现高亮后扣一下打开，再扣一下关闭。房门、厨房六扇柜门和阳台门均使用这个按键。它不是握把侧面的抓握键。
- 右手 B 键：打开或关闭公寓菜单。右手指向菜单按钮，用食指扳机确认。菜单内不能同时走路、转向、瞬移或开门，头部追踪和重力仍保留。

新场景的厨房布局不同，所以六扇活动门改为西侧四扇、北侧两扇。它们在 `DetailedEnvironment/House/Fixtures/Kitchen` 下的 `BaseCab_W_Interactive` 和 `BaseCab_N_Interactive` 中。原实心下柜保留但 inactive，新柜体为空心，关闭时外部尺寸和材质保持不变。冰箱、上柜、抽屉和其他家具没有新增交互。

入户门、两间卧室门和卫生间门已改为扳机开关，不再靠近自动打开或自动关门。右手射线最远 2 米；门外和门内都可以操作。关闭的门仍会挡住瞄准线。

入户门按本次确认改为向外开启，避开玄关鞋柜。开门时不要站在门扇扫过的范围里；鞋柜及台面恢复为本轮升级前的位置，没有为了开门挤进墙内。

阳台门为推拉门。指向任一扇玻璃或边框扣扳机，左扇及边框沿原轨道向右滑动 1.55 米，右扇保持固定；再次扣动关闭。门在运动中仍有碰撞。

## 新手教学怎么进行

每次点击 Play、戴好头显并恢复追踪后，独立欢迎界面询问“是否需要新手教程？”。它不在菜单里。

- 选择“跳过教程”：本次游玩不再出现移动练习、首次门交互教学和常规开门按键文案。目标高亮、阻挡和失败提醒仍保留，可主动按 B 查看按键说明。下次进入 Play 会重新询问。
- 选择“开始教程”：先阅读说明并点击 OK，实际按 B 打开菜单，进入“设置”并点击一种移动方式。即使保留“两种都使用”，也请点击一次。按 B 关闭后开始实际练习。

练习按选择安排：平滑移动练习走路 25 厘米和转向 15°；A 键瞬移练习转向 15°和成功瞬移至少 50 厘米；两种都使用则依次练习走路、转向和瞬移。撞墙原地不动、无效落点、安全重置都不算完成练习。

说明确认后松开扳机、A、B，并让两个摇杆回到中间。每一步只开放当前练习操作。中途可按 B 打开菜单暂停练习；更改移动方式后，未完成的练习会调整，不会要求使用已关闭的操作。

选择开始教程的玩家在自由探索时，首次进入可见门的 2 米范围内，会分别看到房门、柜门、阳台门教学。确认后本次不重复；系统菜单或追踪短暂中断不会清除已完成进度。

## 菜单与安全重置

按 B 打开菜单，右手射线指向按钮后扣一下食指扳机。菜单打开时固定在前方，不会随着每次转头晃动。再次按 B 或点击右上角按钮关闭。

“测距”“标记注释”“我的物品”只有界面入口，显示“暂未开放”，本版没有对应工具。“按键说明”只列出已分配功能的按键，未启用的移动方式有明确标注，不再列出 X、Y、握把等未分配按键。

“退出游戏”打开独立确认面板，只显示标题“退出游戏”和“确认退出”“取消”两个按钮。点击“取消”或按 B 返回来源界面：从菜单进入就回到原菜单页，从参观完成提示进入就回到完成提示。点击“确认退出”结束本次游玩。在 Unity 编辑器通过 Air Link 测试时，只停止 Play，不关闭 Unity 工程；打包运行时退出应用。这些技术解释只写在本说明中，不出现在游戏界面。

参观完成提示同样是独立面板，没有菜单侧栏、菜单标题或底部操作说明。完整标题是“您已看完整个公寓，您可以继续探索和标记注释或者退出游戏”，允许自动换行；只有“继续探索”和“退出游戏”两个按钮。点击“继续探索”恢复游玩，本次不重复提示；按 B 不会关闭此提示或打开菜单。

独立面板出现时固定在玩家前方约 1.2 米，暂停移动、传送和家具操作，保留头部追踪及重力。每次切换面板须松开扳机后重新点击；关闭后还须松开按键、摇杆回中。追踪或焦点中断时隐藏面板并取消待确认退出，恢复后回到来源界面，不会自动退出。

“设置”提供三种移动方式，每次启动默认“两种都使用”，不永久保存：

- 平滑移动：左摇杆行走，A 瞬移关闭。
- A 键瞬移：左摇杆行走关闭，按住 A 瞄准、松开瞬移。
- 两种都使用：同时开启行走和瞬移。

右摇杆连续转向在三种方式下都保留。选择立即生效；关闭菜单、松开按键和摇杆回中后恢复操作。

“设置”下方另有“舒适度调节”子页面，用于减弱晕动。子页每一行都是一个整行目标：右手指向该行，右摇杆向上加一档、向下减一档；也可以直接点该行右侧的 `-` / `+`。可调项为移动暗角、最大移动速度、移动速度平滑、转向速度、转向平滑，另有转向方式（平滑 / 快照）与快照角度；“舒适 / 标准 / 灵敏”三个预设一键写入这些数值，另有“恢复默认”和“返回”。

舒适度数值会保存（`PlayerPrefs`），下次进入 Play 仍然生效；移动方式本身仍不保存，每次启动回到“两种都使用”。暗角只由真实的平滑移动或连续转向触发，静止、瞬移、打开菜单时自动淡出，不会压暗菜单和教学文字。完整范围、取舍与真机验收步骤见 `Docs/ApartmentComfortSettings.md`。

卡住或迷路时，进入“设置 → 返回安全点”，确认“返回”。玩家回到初始入户平台的固定安全点，保持眼高和朝向，不会关门或重置教学进度。它不受 5 米距离、导航连通或 A 键是否启用限制，但目标必须有地板和足够的身体空间。安全点被占用时不会强行传送，追踪丢失时也不会预约一次稍后自动执行的重置。

开发时可在退出 Play 后选择 Hierarchy 根节点 `SafeResetPoint` 调整安全点，必须放在可站立地面上；不要把它拖入 VRPlayer 层级。菜单组件在 `VRPlayer/ApartmentMenu`。普通玩家无需改这些组件。

## 戴头显验证

1. Quest 3 通过 Air Link 进入电脑 Link 环境；如果此前使用 Simulator，先停用模拟器。
2. Unity 双击打开 `Apartment_Detailed_VR`，不要另外添加 Camera Rig 或 XR Origin。
3. 选中 `VRPlayer`，确认 `Apartment VR Locomotion` 的 Debug Mode 未勾选，然后点击 Play。
4. 玩家从入户门外平台开始，先分别验证“开始教程”和“跳过教程”两条流程。每条流程请重新进入一次 Play。跳过后接近各类门，不应出现自动教学。
5. 指向近处空地，按住 A，看到绿色圆圈后松开。依次测试客厅、厨房、卫生间及两间卧室的空地；关闭的门仍会挡住弧线。
6. 在 2 米内检查四扇房门、六扇下柜门和阳台推拉门的高亮与开关。房门、柜门应打开到 90 度，玻璃门平移让出阳台入口；遇到身体或其他门阻挡应停止。
7. 让开障碍后，松开并重新扣扳机，门应继续原方向。长按扳机、换目标、按 A 瞄准时，不应重复或误触发柜门。
8. 按 B 测试六个菜单入口和三种移动方式，确认按键说明同步变化。开启菜单时不能误走路、传送或开门，长按 B 不应反复开关菜单。
9. 离出生平台较远时，测试安全重置的取消和确认；返回后检查位置、眼高和朝向。仅瞬移／仅平滑模式都应能使用安全重置。
10. 打开头显系统菜单再返回，确认没有自动传送、重置或自动续播门；重新松开按键后再操作。停止再进入 Play，所有门默认关闭、移动方式恢复“两种都使用”，欢迎界面重新询问。
11. 完成或跳过教学后，依次进入并离开客厅、厨房、主卧、次卧、卫生间、阳台；进入及离开后各停留约半秒。离开最后一个未完成房间、松开按键后，独立显示“您已看完整个公寓，您可以继续探索和标记注释或者退出游戏”。核对长标题完整、只有两个按钮；此时按 B 无效果。选择“继续探索”后重复进出不再提示。
12. 分别测试菜单与完成提示的“退出游戏”：点击“取消”或按 B 均返回来源界面。长按扳机不会跨面板确认，打开系统菜单再恢复不会误退出。最后测试“确认退出”，确认 Unity 停止 Play 而工程仍打开；重新 Play 后六个区域重新统计。

参观完成是游玩进度通知，不是新手按键教学，因此跳过教程也会收到。走路和瞬移的实际到达位置都能计入；在门口短暂探头、瞬移途经房间不算进入。安全重置和追踪丢失不会伪造离开房间；若在房间里重置，之后重新进出该房间即可完成。入户平台不属于房间。所有参观记录只保留本次 Play。完成提示按确认的文案显示；标记注释仍是菜单占位功能，本次没有实现实际标记工具。

真实身体仍可强行走进虚拟物体，软件碰撞不能代替 Quest 的现实安全边界。测试时保持周围安全；连续转向不舒服时停止测试。

自动检查报告位于 `Logs/M5UpgradeChecks.json`，检查实际门运动、地面落点规则、输入顺序和中文字形。`questVerified` 为 false，直到由佩戴 Quest 的玩家完成真机验收。未连接头显时教学等待追踪，不会自动替玩家完成。

菜单和新教学的检查报告为 `Logs/M6MenuChecks.json`。它覆盖教学分支、按键锁存、移动方式、重置目标检查及中文界面排版；菜单、欢迎和重置确认预览在 `Logs/M6-*.png`。这些是编辑器生成的界面预览，不是头显截图；自动检查不能代替 Air Link 真机验收。

独立完成提示和退出确认的预览分别在 `Logs/M8-TourComplete.png`、`Logs/M8-QuitConfirmation.png`。M6 检查同时验证两个退出来源、取消返回、B 键规则、焦点中断、单一面板、准确文案及排版。独立字体配置入口为 `Apartment Phase 2 → M8 Standalone UI → Apply Standalone UI Font`，支持撤销，重复执行只验证，不重复创建 UI 或改变房间。普通游玩不需要再执行安装。此次修改前备份在 `C:/Users/fzj/Documents/Codex/Backups/standalone-ui-before-20261013-231143`。

## 查看组件与调整速度

选中 `VRPlayer/FurnitureInteractor`，查看 `Apartment Furniture Interactor`：Doors 包含四扇房门和六扇柜门，Sliding Doors 包含阳台门组，交互距离为 2 米。`VRPlayer/Tutorial` 是教学组件。

展开一个 `BaseCab_W_Interactive/Door_1_Hinge`，查看 `Apartment Cabinet Door`。`Degrees Per Second` 默认 90，范围 15 到 180；退出 Play 后修改并保存即可改变开门快慢。不要随意更改铰链位置或角度符号。铰链位于门板前缘角落，门板有厚度，铰链放在厚度中间会让相邻门互撞。

房门使用 `Apartment Room Door`，阳台门组使用 `Apartment Sliding Door`。原房门模型部分嵌入门框、地面和瓷砖，因此实体碰撞盒按实际门洞留出间隙；完整门板另有专用瞄准碰撞面，防止射线从实体盒边缘穿过去。可见模型、门框墙体和铰链位置不变，不要把这两个碰撞体一起删除。

`VRPlayer` 的 Teleport Validation Mode 为 Floor Landing，即地面落点模式。传送检查地面、坡度、距离和目标身体空间；原 NavMesh Surface 与地图资源仍保留，但不再决定精细场景能否传送。走路和门运动继续使用实体碰撞。不要为了扩大可传送范围缩小玩家身体或关闭墙体碰撞。

地毯原碰撞是一片悬浮的薄网格，本副本禁用了它，并增加接到地板的 `CarpetGroundSupport`，可见地毯没有移动。不要把墙、柜门或桌面设为 TeleportFloor。
