# Group 10 - Participant Quick Start

**Purpose:** Review everyday movement and furniture clearances along Entrance -> Living Room -> Kitchen. This simplified design model is not a sales tour or certified measurement.

## Prepare and start

A facilitator should connect Meta Quest 3 through Quest Link, check headset fit and establish a clear physical boundary. Stop if uncomfortable. Stay inside the real boundary even if virtual movement is blocked.

In Unity 6000.6.4f1, open only `Assets/Scenes/Apartment_Detailed_VR.unity`, then enter Play. The scene includes its rig.

**Build Generated:** `Group10_Phase2_WindowsBuild.zip`. Extract the whole ZIP, keep every runtime file, enter Quest Link and launch `Group10_Phase2.exe`. **The EXE has not been run: Player behavior, font readability and course-PC compatibility are NOT VERIFIED.** Publication remains Pending; see [Verification Summary](Verification_Summary.md).

## Controls

- **Left stick:** smooth movement when enabled. **Right stick:** turn.
- **Right A:** hold to aim teleport; release on a valid green destination.
- **Right B:** open/close the menu. Point with the right controller and press its front **Trigger** to choose items or operate nearby doors.
- **Either side Grip:** hold near the bag handle to carry; release to put down. One hand holds at a time.

Each new Play/Player starts English. **B > Settings > Language > 简体中文** changes this session's UI. After menu/focus interruptions, release Grip and neutralise controls before trying again.

## Follow the review guide

Practise movement, enter and explore the living room. Try the balcony sliding door and open/close the designated kitchen cabinet. Return to the entrance; choose **My Items > Small / Medium / Large** while the bag is released, then pick it up. Carry through the living room to the kitchen and release into the outlined **floor area**, not a cupboard.

Red furniture and holding-hand vibration indicate registered contact. Move clear; warnings do not physically block you. Put down before changing size.

Select **Measurement > Start measurement**, then Trigger two surface points. Select **Markers > Place marker**, choose feedback, importance and an optional measurement link, then **Save feedback**. Read the result; retry on a storage error. Explore freely or use the menu's Exit confirmation.

## Correct mistakes and recover

**Cancel start point** cancels unfinished measurement. **Undo last display / Hide measurements** hides displays without erasing history. **Cancel draft** corrects an eligible new marker; **Hide marker** preserves saved feedback. **Stop tool** restores normal interaction.

If virtually stuck: **B > Settings > Teleport to Safe Position**, confirm, release controls and resume. Help: **B > Controls > Review guide**. Skipped tasks remain skipped. On reopening, saved data remains while old visuals stay hidden.
